## What I learned
- **Layout:** Flexbox and Grid with `auto-fit`/`minmax` make responsive pages without many media queries.
- **JavaScript habits:** guard clauses, small pure functions, and never mutating inputs make code easier to test.
- **DOM safety:** build elements with `createElement` and `textContent`, not `innerHTML`.
- **State and storage:** keep one source of truth, then load, update, save and render.
- **Testing:** writing tests for edge cases (empty, boundary, invalid) found problems before the browser did.
