# Assignment 12: Make Previous Projects Responsive

## Checklist applied to every project
- `<meta name="viewport" content="width=device-width, initial-scale=1">` in every page
- `box-sizing: border-box` so padding does not cause overflow
- Flexbox `wrap` or CSS Grid `auto-fit` instead of fixed widths
- `@media` queries at about 600-700px for small screens
- Tested at 360px, 768px and 1280px widths

## Changes
| Project | Change |
|---------|--------|
| A1 Styled page | Smaller header and heading, tighter section padding under 600px |
| A2 Resume | Single-column skills and certificates, stacked education rows under 600px |
| A3 Profile card | Card becomes full-width under 360px |
| A4 Landing section | Smaller hero text and padding; feature cards go full-width under 600px |
| A5-A8 | Already responsive (media queries or flex-wrap built in) |

## How to test
Open a page, press F12, click the device toolbar icon, and try different screen sizes.
