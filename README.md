## Run
- **Pages:** open any `index.html` in a browser. No build step.
- **Node tests:** inside a folder run `node tests.js` (or `node test.js`). Capstone: `cd capstone-studytrack && npm test`.
- **JavaScript exercises:** `node script.js` prints the same output you see in the page.

## Conventions
- Each assignment lives in `day-XX/aNN-name/`.
- User text is shown with `textContent`, never `innerHTML`.
- Logic is kept in pure functions that can be tested without a browser.
